# Code of Conduct

## The short version

Be decent to people. Criticise code, not the person who wrote it. Assume the
person on the other side is doing their best with the time and information they
have.

This project is maintained by one person as a side project. Patience is
appreciated, and so is a well-written issue.

## Expected behaviour

- Keep discussion technical, specific, and about the work.
- Accept that "no" is a legitimate answer to a feature request, and that a
  maintainer's time budget is a real constraint.
- Respect the project's language conventions (see [CONTRIBUTING.md](CONTRIBUTING.md));
  writing in English or Vietnamese is equally welcome.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory or sexualised comments, publishing
someone's private information, and persistent disruption after being asked to
stop.

## Enforcement

Report a problem privately through the maintainer's GitHub profile
([@xuantinhnbs-rgb](https://github.com/xuantinhnbs-rgb)) or, if it concerns
something posted in this repository, via
[GitHub's private reporting form](https://github.com/xuantinhnbs-rgb/autocad-trimble-mcp/security/advisories/new).

The maintainer may edit, hide, lock or delete contributions, and block
accounts, in response to behaviour that breaks this document. Decisions are
final and do not come with an appeals process — again, one person, side
project.

## Attribution

This is a deliberately short document, written for a small project. If it ever
outgrows that, it will be replaced by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
